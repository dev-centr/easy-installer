= Changelog

== 2026-08-06 — v0.2.0 Ibex rebrand

* Product rename: **Ibex** (Install Builder EXtension); CLI `ibex`
* Logo: `assets/ibex.svg` + PNG for shell package
* Release assets: `ibex-*` (dual-ship `easy-installer-*` for one major line)
* Packaging: winget `DevCentr.Ibex`, Homebrew tap formula, Scoop manifest
* `ci-runner.sdl` pin field `ibex` (alias `easyInstaller` still parsed)

== 2026-08-06 — CI workflow emit (no package build)

* `ci-runner.sdl` profile + `emit-ci` / `new-project --intent=ci-pipeline`
* Emitters: GitHub Actions, GitLab CI, Azure Pipelines, Jenkins, CircleCI, Bitbucket Pipelines
* Always writes `CI-INSTALLER.adoc` (enable, secrets, tags, artifacts, pins)
* Shell menus: New Installer CI pipeline
* Docs: xref:howto-emit-ci.adoc[How-to: emit CI pipelines]

== 2026-08-06 — v0.1.0 initial release

* Host CLI: `inplace-path`, `new-project`, `build`, `plugins`, `shell`, `--version`, `debug-dump`
* Built-in plugins: portable-zip, nsis, inno, msi, msix, appimage
* msi-generator bridge for MSI/MSIX plugins
* Win11 sparse package + classic fallback; macOS Quick Action; Linux file-manager adapters
* Installer project format: `installer.kdl`
* Antora docs component wired into docs.devcentr.org hub
