= Easy Installer
:description: Cross-platform installer project host with plugins and Install in-place (add to PATH).
:navtitle: Introduction

Easy Installer is a CLI (and DevCentr surface) for two jobs that Windows and other OS shells leave unfinished:

* **Install in-place (add to PATH)** — put a folder on the user PATH so binaries inside it run without a full package install.
* **Installer projects** — scaffold `installer.kdl`, pick a backend plugin, and build artifacts (portable zip, NSIS, Inno, MSI/MSIX via msi-generator, AppImage stubs).

== Get the binary

* Releases: link:https://github.com/dev-centr/easy-installer/releases[GitHub Releases]
* After install: `easy-installer shell install` for file-manager menus

== Commands (quick)

[source,bash]
----
easy-installer inplace-path add .
easy-installer new-project . --plugin=portable-zip
easy-installer build .
easy-installer plugins list
easy-installer plugins install-gui inno
----
