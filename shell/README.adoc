= Shell (Explorer / file managers)
:description: Building and registering Ibex OS menus.

== Windows Explorer DLL

Build with MSVC (see `explorer_command/build.ps1`). Output: `EasyInstallerExplorerCommand.dll` (filename kept for CLSID stability; UI title is **Ibex**).

Sparse package: `sparse-package/AppxManifest.xml` (`DevCentr.Ibex.Shell`, executable `ibex.exe`).

== Install

[source,bash]
----
ibex shell install
----
