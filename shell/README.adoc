= Shell integration
:description: OS file-manager hooks for easy-installer.

== Windows

* **Win11 (preferred):** build `shell/explorer_command` with MSVC (`pwsh ./build.ps1`), then `easy-installer shell install` registers the sparse package.
* **Fallback:** classic HKCU cascading menu + `.easyinstaller` ShellNew type when modern registration is unavailable (no DLL, older Windows, unsigned package).

== macOS

`shell install` writes Quick Action instructions under `~/Library/Services`.

== Linux

DES-EMA actions under `~/.local/share/file-manager/actions/` plus a Nemo action.
